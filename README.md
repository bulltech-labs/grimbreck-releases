# Grimbreck: downloads

Aqui ficam só os **Releases** do Grimbreck (o jogo e o launcher). O código não fica neste repositório.

Para jogar, baixe o **launcher** do último Release (`launcher-windows.zip` ou `launcher-linux.zip`), abra e clique em
Jogar: ele baixa e atualiza o jogo sozinho. Para criar a conta você precisa de um **código de convite** da equipe.
